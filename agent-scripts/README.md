# Agent Scripts Sandbox

This directory (`agent-scripts/`) is dedicated to all automated scripts, scrapers, data processing pipelines, experimental utilities, and artifacts written by Gemini Antigravity.

## Purpose & Conventions

1. **Separation of Concerns**: Production and human-authored modules reside in `src/`, while human-curated operational scripts remain outside this directory. Any automated or AI-assisted utility script belongs here.
2. **Environment & Imports**: All scripts in this directory resolve the repository root dynamically and import modules directly from `src/` (e.g., `china_causal_kg`).
3. **Artifacts & Output**: Generated reports, diagnostic outputs, and scratch artifacts generated by agent runs are placed in `agent-scripts/artifacts/` or the designated project `data/` directories.

## Directory Structure

```text
agent-scripts/
├── artifacts/          # Generated output files, reports, and run artifacts
├── scrape_hkpl.py      # Runner for the HKPL MMIS newspaper scraper
└── README.md           # Workspace guide and conventions
```
