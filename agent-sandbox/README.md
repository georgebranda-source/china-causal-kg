# Agent Sandbox

This directory (`agent-sandbox/`) is dedicated to all automated code, packages, scripts, scrapers, data processing pipelines, experimental utilities, and artifacts written by Gemini Antigravity.

## Purpose & Conventions

1. **Separation of Concerns**: Human-maintained items are strictly limited to `data/`, `docs/`, `.gitignore`, and the root `README.md`. All agent-authored source code, modules, utilities, and runner scripts reside entirely within `agent-sandbox/`.
2. **Environment & Imports**: Scripts and modules within `agent-sandbox/` can import the internal package `china_causal_kg` from `agent-sandbox/src/`.
3. **Artifacts & Output**: Generated reports, diagnostic outputs, and scratch artifacts generated by agent runs are placed in `agent-sandbox/artifacts/` or designated project `data/` directories.

## Directory Structure

```text
agent-sandbox/
├── artifacts/          # Generated output files, reports, and run artifacts
├── src/                # Agent-created library packages (e.g. china_causal_kg)
│   └── china_causal_kg/
│       ├── __init__.py
│       └── ingestion/
│           ├── __init__.py
│           └── hkpl_scraper.py
├── scrape_hkpl.py      # Runner for the HKPL MMIS newspaper scraper
└── README.md           # Workspace guide and conventions
```
