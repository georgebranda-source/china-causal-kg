How it was built

  1. Extraction.
  2. Descriptions. The local model wrote a one-sentence description of each cause and effect from the full article.
  3. Grouping.
  4. Graph. Claims between the same two groups are merged into one arrow. Claims with cause and effect in the same group can't be arrows, so they're listed on the node.

How to read it

Arrows record what the paper or its sources claimed, not established causes. This run doesn't record who made each claim, so reported speech, Reuter cables and the paper's own voice look the same here.

The sidebar shows how many claims sit inside a node instead of forming an arrow.

Limits of this draft

Nothing here has been hand-checked. Node names are each group's most central description. Colours come from keyword counts and can be wrong. Notices reprinted on several days are counted each time, so some arrows look stronger than they are. Two counterfactual descriptions are known to be wrong.
